TicketDesk — AI Customer Support Demo

How to test the AI chat

Click the floating 💬 Chat button at the bottom-right of this page to open the widget.

  1. Try the suggested chips (Order status, Refund, Password reset, Talk to a human).
  2. Type any question. The mock AI searches the knowledge base and replies.
  3. Type "talk to a human" — the AI escalates and creates a real ticket in the ticketing app.
  4. Open index.html in another tab to see the new ticket appear in the list.

How AI escalation works

Customer asks a question in the chat widget → AI bot searches the knowledge base → if it knows the answer, replies instantly. If confidence is low or the customer asks for a human, the AI calls Escalate.toTicket() which creates a real ticket in the existing system.

The ticket arrives in the agent's list with:

  • Auto-generated subject (first customer message)
  • Full conversation transcript as the description
  • AI-suggested priority (URGENT / HIGH / MEDIUM / LOW)
  • AI-suggested tags (billing, shipping, technical…)
  • A "🤖 AI-Escalated" badge in the ticket header

🤖 AI Configuration

Admins can configure the AI in Settings → AI Configuration: provider (OpenAI / Anthropic / Gemini), model, API key, escalation threshold, knowledge base files, welcome message, and suggested questions.
